# 开源范围

公开仓库只保留运行网站、复用 72 种版式、维护内容和部署所需的文件。

## 适合公开

- `src/`、入口文件和 TypeScript/Vite 配置：网站源代码。
- `data/`：72 种版式与 8 个分类的结构化信息。
- `public/images/layouts/`：72 张高清 PNG 和响应式 WebP。
- `skills/typography-layout-advisor/`：配套 Skill、完整目录、查询脚本和预览图。
- `scripts/` 中的数据校验、图片优化、README/Skill 同步和部署整理脚本。
- `tests/`、Playwright 配置、Cloudflare 配置、README 与开源许可。

## 仅保留在本机

- `AGENTS.md`：包含本机项目边界、绝对路径和代理操作说明。
- `source-archive/`：内部 brief、生成日志、提示词、调研与复盘。
- `design-demos/`：历史方案、失败稿、验证脚本和大量过程截图。
- 内部迁移记录、确认过程、实现日志和早期完整计划。
- `dist/`、测试结果、日志、缓存、依赖目录和环境变量文件。

上述本机目录已写入 `.gitignore`。公开文件中不保存 GitHub、Cloudflare 或其他服务的访问令牌；部署认证由本机凭据管理。
